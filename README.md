# Hossain Ali Food and Beverage Ltd Website

A modern, responsive website for Hossain Ali Food and Beverage Ltd, a fruit processing and distribution company based in Bangladesh.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations
- Detailed information about the company and its products
- Contact form for inquiries
- Product showcase with filtering options
- Company history and values
- Team and partners sections

## Pages

- **Home**: Company introduction, featured products, testimonials
- **About**: Company history, mission, vision, values, and team
- **Explore**: Product catalog with filtering options
- **Contact**: Contact form, company information, and FAQ

## Technologies Used

- React.js
- React Router for navigation
- CSS for styling
- Font Awesome for icons

## Getting Started

### Prerequisites

- Node.js and npm installed

### Installation

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`

## Build for Production

```
npm run build
```
